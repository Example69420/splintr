# Audio demos & media

**Accessibility projects have to be *heard*.** These files let you experience
SoundKey without a Flipper. Everything here is generated by the project and
regenerable from a clean clone.

## Regenerate

```bash
# Audio: one WAV per demo flow (+ caption transcript) and one per cue
cd sim && python3 -m soundkey_sim.cli export-demos ../media

# Animated demo GIF of the "locate a tag" flow
python3 media/generate_gif.py
```

## What's here

| File(s) | What |
|---|---|
| `demo_locate_tag.gif` | Animated geiger-locate demo — pair it with `flow_locate_tag.wav` to hear it |
| `flow_*.wav` | A full task rendered to audio (locate, classify, battery, help) |
| `flow_*.txt` | The caption transcript (what a TTS voice would say), time-aligned |
| `cue_*.wav` | One sample per cue in the [sound-cue legend](../figures/legend.md) |
| `MANIFEST.md` | Generated index of the demos |

> Tip: start with `flow_locate_tag.wav` — you'll hear the click-rate accelerate
> as the target gets closer, then the bright "found" motif. That single clip is
> the fastest way to understand what SoundKey does.
